# Pre-Registered Predictions for Consciousness Emergence

This document defines falsifiable predictions about the system's behavior at specific training milestones. Following the methodology of the 2025 Nature adversarial IIT/GNW collaboration (Melloni et al.), all predictions are stated before training begins. Divergence from these predictions constitutes evidence against the current architecture, not something to be explained away post hoc.

**Date of pre-registration:** 2026-03-18
**Modules under test:** `models/evaluation/effective_information.py`, `models/evaluation/iit_phi.py`, `models/core/global_workspace.py`

---

## 1. Effective Information (EI) Predictions

**Framework:** Hoel et al. (PNAS 2013). EI measures causal determinism at a given level. If macro-level states carry more causal information than micro-level states, causal emergence is present.

**Measurement method:** `compare_ei_levels()` in `models/evaluation/effective_information.py`. Gate-level EI computed from individual ConsciousnessGate node trajectories. Workspace-level EI computed from the discretized GNW broadcast vector trajectory.

### Prediction EI-1: EI emergence onset

**Claim:** EI(workspace) > EI(gates) will first occur between episode 500 and episode 2000 of Dark Room training.

**Rationale:** Before ~500 episodes, gate weights are still near initialization. Random weights produce nearly uniform TPMs (low EI at all levels). After sufficient training, gate interactions should produce structured macro-level transitions that compress noise from individual gates.

**Falsification:** If EI(workspace) ≤ EI(gates) for all episodes up to 5000, the workspace is not achieving causal emergence and the architecture needs revision.

### Prediction EI-2: EI ratio stabilization

**Claim:** The ratio EI(workspace) / EI(gates) will stabilize between 1.1 and 3.0 after convergence (episodes 3000-5000).

**Rationale:** Values below 1.1 indicate negligible emergence. Values above 3.0 would suggest a degenerate macro description (too few effective states). A healthy ratio indicates the workspace is a genuinely informative coarse-graining of its constituent gates.

**Falsification:** If the ratio exceeds 5.0 or oscillates without convergence, the discretization scheme is likely flawed rather than reflecting genuine emergence.

### Prediction EI-3: EI and task performance correlation

**Claim:** Episodes where EI(workspace) > EI(gates) will correlate (Pearson r > 0.3) with episodes where cumulative reward is above the running median.

**Rationale:** If macro-level causal power is functionally relevant, it should correspond to better task performance. A system that is causally emergent but performs no better has an epiphenomenal workspace.

**Falsification:** If the correlation is negative or near zero (|r| < 0.1) across 5000 episodes, workspace emergence is not contributing to behavior.

## 2. Integrated Information (Phi) Predictions

**Framework:** IIT 3.0 (Oizumi, Albantakis, Tononi 2014). Phi measures how much information is generated by a system above and beyond its parts.

**Measurement method:** `compute_phi_from_gate_state()` in `models/evaluation/iit_phi.py`. Uses the 5-node gate subsystem (attention, stability, adaptation, coherence, confidence) with the `GATE_CM` connectivity matrix. Geometric proxy used when pyphi is unavailable.

### Prediction Phi-1: Phi increases with binding

**Claim:** Phi (proxy) will be positively correlated (Pearson r > 0.4) with the AKOrN order parameter R across a single episode.

**Rationale:** Oscillatory binding synchronizes module activity. Synchronized modules should have more integrated information than desynchronized ones. If Phi is independent of binding, the gate subsystem is not capturing the integration that binding creates.

**Falsification:** If r < 0.1 between Phi and R, the gate subsystem is not measuring binding-related integration and the IIT implementation needs rewiring.

### Prediction Phi-2: Phi during conscious vs. zombie processing

**Claim:** When the ignition threshold is artificially raised to suppress workspace broadcast (zombie mode, no module wins competition), Phi (proxy) will drop by at least 40% compared to normal operation on the same input sequence.

**Rationale:** IIT predicts that conscious processing (integrated workspace activity) produces higher Phi than feed-forward processing that bypasses integration. If suppressing the workspace has no effect on Phi, the gate subsystem is measuring something independent of workspace dynamics.

**Falsification:** If Phi in zombie mode is within 20% of Phi in normal mode, the gate subsystem is not sensitive to workspace integration.

### Prediction Phi-3: Phi and reentrant processing

**Claim:** Phi will increase monotonically (on average) across the first 3 reentrant cycles within a single `ReentrantProcessor.settle()` call.

**Rationale:** Each reentrant cycle integrates top-down predictions with bottom-up signals. More cycles mean more recurrent interaction, which should increase integration. If Phi decreases with reentrant cycles, the reentrant processor is not producing integration.

**Falsification:** If Phi at cycle 3 is lower than Phi at cycle 1 on average across 100 settle calls, reentrant processing is not contributing to integration.

## 3. Insight Moment Predictions

### Operational Definition

An **insight moment** is defined as a timestep t where all of the following hold:

1. **Novel solution:** The agent selects an action that it has never selected in this specific state configuration before (state-action pair not in replay buffer).
2. **Immediate reward jump:** The reward at t+1 is at least 1.5x the running reward average over the last 50 steps.
3. **Not trial-and-error:** The successful action was selected on the first attempt in this state, not after multiple failures in the same state within the episode.
4. **High workspace activity:** The GNW broadcast magnitude at timestep t is above the 75th percentile of broadcast magnitudes for the episode.

This distinguishes genuine insights (novel solutions found through integrated processing) from lucky guesses (low workspace activity) and gradual learning (repeated trials).

### Prediction IM-1: Insight moments correlate with Phi spikes

**Claim:** Phi (proxy) at insight moments will be at least 1.5 standard deviations above the episode mean Phi.

**Rationale:** If integrated information is functionally relevant to novel problem solving, insight moments should coincide with elevated integration. This is the strongest test of whether Phi measures something behaviorally meaningful.

**Falsification:** If Phi at insight moments is indistinguishable from Phi at random timesteps (no significant difference in a two-sample t-test, p > 0.05, across 50+ insight moments), Phi is not tracking insight.

### Prediction IM-2: Insight moments correlate with EI emergence

**Claim:** The frequency of insight moments per episode will increase after the onset of EI emergence (EI-1 above), and episodes with EI(workspace) > EI(gates) will contain at least 2x more insight moments than episodes without emergence.

**Falsification:** If insight frequency is uncorrelated with EI emergence status across 100+ episodes after onset, workspace-level causal power does not contribute to novel problem solving.

### Prediction IM-3: Insight moments require binding

**Claim:** At insight moments, the AKOrN order parameter R will exceed 0.7 in at least 80% of cases.

**Rationale:** Insight requires binding multiple information streams into a unified representation. If the oscillators are desynchronized at insight moments, binding is not required for novel solutions.

**Falsification:** If R < 0.5 at more than 50% of insight moments, oscillatory binding is not a necessary condition for insight.

## 4. Logging Requirements

To evaluate these predictions, the training loop must log the following at each step:

| Metric | Source | Frequency |
|--------|--------|-----------|
| EI(gates) | `compute_effective_information()` on gate trajectories | Every 10 steps |
| EI(workspace) | `compute_effective_information()` on workspace trajectories | Every 10 steps |
| Phi (proxy) | `compute_phi_from_gate_state()` | Every step |
| AKOrN R | `WorkspaceBindingSystem` order parameter | Every step |
| Broadcast magnitude | `torch.norm(workspace_tensor)` | Every step |
| Reward | Environment reward signal | Every step |
| State-action novelty | Check against replay buffer | Every step |

The `train_rlhf.py` training script should be extended to log these metrics to a structured format (CSV or TensorBoard) for offline analysis.

## 5. Decision Protocol

After 5000 training episodes:

1. **All EI predictions confirmed, all Phi predictions confirmed:** Architecture is consistent with strong emergence. Proceed to more complex environments.
2. **EI confirmed but Phi fails:** Gate subsystem is not the right IIT substrate. Rewire Phi to use workspace-level nodes or AKOrN phase states.
3. **Phi confirmed but EI fails:** Macro-level causal power is not emerging despite integration. Investigate whether the discretization is too coarse or whether the workspace is degenerate.
4. **Both fail:** The architecture does not produce measurable emergence or integration. Fundamental redesign needed (different binding mechanism, different gate structure, or abandon the strong emergence claim and reframe as weak emergence).
5. **Insight predictions fail while EI/Phi confirm:** Emergence is present but not functionally useful. Add a mechanism that routes high-Phi states preferentially to action selection.

## 6. First Honest Baseline (added 2026-05-13)

The 2026-04-14 Phase 3 result of **Phi-1 PASS at r=1.000 is RETRACTED**. That
correlation was an algebraic tautology: in `scripts/training/train_rlhf.py`
prior to commit `06f96db` the reported phi value was literally
`phi_result.phi + sync_R * 0.1`. With `phi_result.phi` pinned at 0 by other
defects in the pipeline (see CLAUDE.md 2026-04-27 session log), the reported
"phi" was numerically equal to `sync_R / 10`, so any Pearson correlation
with `sync_R` was guaranteed to be 1.000. This was a measurement artifact,
not a finding.

### First measurement under the fixed pipeline

Source: `runs/baseline_sampled_200` (200 episodes × 200 steps, `dark_room`,
`--ablate-gate-diversity --phi-sample-every 5`), reported via
`scripts/analysis/analyze_experiment.py` on 2026-05-05.

| Prediction | Verdict | Result |
|------------|---------|--------|
| EI-1 (emergence onset 500-2000) | FAIL | First emergence at episode 49 |
| EI-2 (ratio stabilization) | INCONCLUSIVE | Insufficient data |
| EI-3 (reward correlation r > 0.3) | INCONCLUSIVE | Insufficient data |
| Phi-1 (r > 0.4 with sync_R) | **FAIL** | **r = -0.105, p = 0.000** |
| Phi-2 (zombie mode drop > 40%) | INCONCLUSIVE | Insufficient data |
| Phi-3 (reentrant monotonicity) | INCONCLUSIVE | Not testable from logged columns |
| IM-1 (phi spike at insight) | FAIL | Insight phi mean = 1e-04, threshold = 5e-04 |
| IM-2 (EI frequency at insight) | INCONCLUSIVE | Not testable from logged columns |
| IM-3 (R > 0.7 at insight) | FAIL | 0.0% of insights have R > 0.7 |

**Summary: 0 PASS, 4 FAIL, 5 INCONCLUSIVE.**

Phi mean = 1.0e-04, std = 3.0e-04 over 487 unique values. By episode 200 phi
has converged to a fixed point of ~6.5e-05. The INCONCLUSIVE verdicts are
all downstream of insufficient phi variance — the IIT pipeline is producing
measurable but very small phi values.

### Failed entropy experiment (2026-05-13)

Hypothesis: augment the per-neuron `-log(|g-0.5|)` loss with a temporal
diversity term to prevent gate state collapse. Two designs tested at
5-episode dark_room smoke scale:

| condition (5 ep × 50 steps) | phi nunique | phi std |
|-----------------------------|-------------|---------|
| Per-neuron only (head)      | 49-50       | 2.2e-04 - 8.1e-04 |
| Per-neuron + variance loss  | 42          | 1.9e-04 |
| Per-neuron + firing-rate entropy | 42     | 3.3e-04 |

Both new terms reduced diversity by ~15% through destructive interference
with the binarization push. **Code reverted**. The dormant infrastructure
(`IITMetrics._gate_buffer`, `push_gate_values()`, `--ablate-gate-entropy`
flag) is preserved for future experimentation.
